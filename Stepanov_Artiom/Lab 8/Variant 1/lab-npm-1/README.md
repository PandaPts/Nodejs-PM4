# Лабораторная работа 8 — Вариант 1

## Где выполнено каждое задание

1. **Инициализация проекта и версия 0.1.0** — `package.json`, поля `name` и `version`.
2. **Установка генератора ID** — `nanoid` в `dependencies`; генерация ID также показана в `app.js`.
3. **Приложение и запуск** — `app.js`; команда `npm start` настроена в `scripts` файла `package.json`.
4. **Разработка через nodemon** — `nodemon` в `devDependencies`; команда `npm run dev` настроена в `scripts` файла `package.json`.
5. **Переносимость** — `package-lock.json` фиксирует версии зависимостей. После удаления `node_modules` запустите `npm install`, чтобы восстановить их.

`package.json` оставлен в формате JSON: в нём нельзя писать комментарии, иначе npm не сможет прочитать файл.
