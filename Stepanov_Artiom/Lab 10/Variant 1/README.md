# Лабораторная работа 10 — Вариант 1

Запуск сервера:

```sh
node server.js
```

Сервер слушает порт `3000`.

- Любой адрес, кроме специальных маршрутов: `200 OK`, приветствие и русский текст в UTF-8.
- `/admin`: `403 Forbidden`, текст «Доступ ограничен».
- `/html`: `200 OK`, HTML-заголовок «Инфо-панель».
- Каждый запрос выводит в консоль метод и `User-Agent`.

Проверка из второго терминала:

```sh
curl -i http://localhost:3000/
curl -i http://localhost:3000/admin
curl -i http://localhost:3000/html
```
