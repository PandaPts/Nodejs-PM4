# Лабораторная работа 9 — Вариант 1

- **npm-проект и зависимости** — `package.json`: `dotenv` — основная зависимость, `nodemon` — зависимость разработки.
- **Критический параметр** — `.env`: `LIMIT` задаёт порог подозрительного перевода.
- **Событийный канал** — `events.js` экспортирует общий `EventEmitter`.
- **События переводов** — `transfers.js` отправляет `transfer` для суммы не выше лимита и `fraud-alert` для суммы выше лимита.
- **Мониторинг** — `app.js` загружает `.env`, подписывается на события и генерирует случайный перевод каждые три секунды.
- **Задание 1** — настройка `LIMIT` в `.env`; загрузка и чтение параметра в `app.js`.
- **Задание 2** — события в `events.js`, подписчики в `app.js`, отправка событий в `transfers.js`.
- **Задание 3** — генерация переводов и вывод сообщений в `app.js`; проверка порога в `transfers.js`.
- **Общие требования 1–3** — npm-настройки и зависимости в `package.json` (`init`, `dotenv`, `nodemon`, скрипт `dev`).

Запуск:

```sh
npm start
```

Режим разработки с перезапуском при изменениях в `.js` и `.env`:

```sh
npm run dev
```

Проверка маршрутизации событий:

```sh
npm test
```
